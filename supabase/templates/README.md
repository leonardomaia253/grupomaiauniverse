# Templates do Supabase Auth

Templates transacionais do Grupo Maia aplicados ao projeto Supabase `wfrhfjiklucmvvsetduf`.

- `confirmation.html`: confirmação de cadastro
- `invite.html`: convite de usuário
- `magic-link.html`: acesso sem senha
- `recovery.html`: recuperação de senha
- `email-change.html`: alteração de e-mail
- `reauthentication.html`: verificação de segurança por código

Os arquivos usam apenas CSS inline e variáveis oficiais do GoTrue para manter compatibilidade entre clientes de e-mail.
