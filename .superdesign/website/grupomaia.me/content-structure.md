# Grupo Maia

## Business Context
- **Type/Industry:** Brazilian holding company / corporate portfolio
- **What they do:** Structure companies, technology, data, and governance to transform operations into measurable growth
- **Target audience:** Investors, institutional partners, company leadership
- **Page goal:** Introduce holding's vision, showcase 23-company portfolio, route stakeholders to investor relations or contact

# Page Layout & Structure

### Hero
Left-aligned h1 ("Construímos valor com visão de longo prazo.") set in tight letter-spacing display type, positioned above a 3-cell vertical stack: h3 "Governança" + descriptor, h3 "Operação" + descriptor, h3 "Permanência" + descriptor — each cell outlined in muted green with muted green text on beige background. Right side: centered column of supporting copy, h3 "O Grupo Maia reúne...", then two stacked links — "Conhecer o portfólio" (primary action in muted green) and "Investidores e parceiros" (secondary, numbered "01"). Small callout text top-right "Grupo empresarial brasileiro · São Paulo · 2026". Primary interaction: "Conhecer o portfólio" link anchors to portfolio section below.

### Header / Navigation
Fixed horizontal bar: left-aligned "A GRUPO MAIA" logotype, center 5 text links (Empresas, Sobre, Contato — exact names from nav), right-side "INSTITUCIONAL" label + "Entrar" button in muted green accent. No hamburger; full-width layout.

### Portfolio Grid
- **Purpose:** Present 23 companies/initiatives with logos, category labels, and entry points.
- **Layout:** Uniform 2-column grid, 23 cells total. Each cell: small sequential number (01–23) in gray, square company logo or icon (1:1 ratio, some 0.84:1 or 0.67:1 variants), h3 company name in muted green, category label (real estate / marketplace / ai tech / etc.) in gray text, right-aligned "+" chevron. Cells separated by cream backgrounds; alternating row backgrounds (white, cream). No images bleeding; contained thumbnails only.

### "Empresas com autonomia" Section
- **Purpose:** Transition heading + context for portfolio below.
- **Layout:** Centered h2 headline over 2-line descriptor paragraph in muted green, then portfolio grid begins immediately below.

### "Uma conversa começa com contexto" Section
- **Purpose:** Route institutional stakeholders to dedicated resources.
- **Layout:** Light green background; centered h2 headline, 3-line descriptor, then two stacked links — "Falar com relações institucionais" (primary, muted green) and "Acessar área privada" (secondary). Right side contains decorative image asset.

### CTA Section — "Vamos marcar uma conversa."
- **Purpose:** Lead capture for strategic conversation requests.
- **Layout:** Dark background (near-black); left column h2 headline + 2-line copy in white; right column contains form: 2 text input fields (side-by-side), 1 textarea, 1 "Enviar mensagem" button (white text on muted green). Form fields: white backgrounds, muted green border on focus.

### Footer
- **Purpose:** Legal, navigation, and holding info.
- **Layout:** Dark background matching CTA section; left column: small logo + single descriptor line; center column: 3 footer links (Menu / Empresas / Contato estratégico); right column: Portal link. Fine print copyright bottom.

**Notable patterns:** 
- Portfolio grid: uniform 2-column layout, 23 equal cells, white/cream background alternation per row, all images contained (no bleed).
- Hero uses 3-cell vertical accent stack on left; right side info column creates asymmetry.
- Background alternation: beige → light green → dark (near-black) for major sections.
- All interactive elements (links, form) use muted green as primary accent; white as secondary accent on dark backgrounds.
- :focus-visible present on all inputs; prefers-reduced-motion honored throughout.
- Navigation is fixed, sticky across scroll.
